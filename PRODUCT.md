# PolCam Monitoring

PolCam Monitoring is a map application for exploring connected public data sources and demonstrating OmniMotion monitoring workflows. Operators select sources, inspect objects and cameras, navigate cities and prepare scene presentations. A map object must retain its source, timestamp and factual limitations; simulated layers are not observed vehicle positions.

The existing Cesium viewer, data-layer lifecycle, camera controls, recording, voice controls, source attribution and Hamburg signal/RSU integration remain functional. PolCam/WB trademarks retain their separate ownership. The public fork contains implementation and technical documentation, not private OmniMotion planning.

The owner's requested direction is an original PolCam HUD and layout in the visual style of WB Group, with no peripheral map darkening. The interface must remain usable on desktop and small touch screens. This document records the owner's conversation brief and the existing application, not a new product capability claim.
